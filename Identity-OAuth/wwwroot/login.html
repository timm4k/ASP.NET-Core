Google sign-in needs setup

  1. Open a terminal in the project folder and save both Google Cloud credentials in .NET User Secrets dotnet user-secrets set "Google:ClientId" "YOUR_CLIENT_ID" dotnet user-secrets set "Google:ClientSecret" "YOUR_CLIENT_SECRET"
  2. Register this authorized redirect URI in Google Cloud Loading callback URL
  3. Restart the application and open this page again
